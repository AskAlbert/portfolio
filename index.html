Discord bot

GitHub

A Discord bot written in Python that sends a message when a new update is available for the Fairphone 4. This is accomplished by running a web crawler on a forum page about the phone every 24 hours. The project was developed to get insight and understanding of how Discord bots and web crawlers work.

A timer that guides your tooth brushing tooth by tooth, written in JavaScript. This project was developed to get a basic understanding of how SVGs could be utilized in web development.
